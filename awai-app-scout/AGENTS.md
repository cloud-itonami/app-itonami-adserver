# Koukoku Scout

Follow the workspace AGENTS.md, including the Kotoba end-user apps contract.

- The common domain is `.cljc` (`src/scout/domain.cljc`), and the UI is CLJS through Squint with the pinned `@awai/ui`. Tauri v3 is a thin host. Do not fork the UI components or the consent logic.
- The only external request is one GET of the public export, through the canonical client runtime broker with `each-operation` consent. Keep the CSP `connect-src` equal to `clientRuntimeConnectSrc` of the descriptor.
- The export rules in `scout.domain/row-problem` mirror `../scripts/adnetwork_public_export.py`. Change both together. A file that fails them is refused, not repaired or partly shown, and a missing file (404) is "not published", never "0 advertisers".
- `profiles/paired-profile.json` is generated by `scripts/paired_profile.py` from `../hermes/profiles/adnetwork-scout`. Do not edit it by hand.
- Do not send outreach, write the catalog, publish the export, or launch or reconfigure the bot from this app.
- Keep source, build, device, distribution and live-operation evidence separate, and record unknowns as unknown.
